# Plot samples associated to risk level

Plots a pichart showing the percentages of samples associated to each
risk level

## Usage

``` r
plot_risk_summ_sampleset(df_conta)
```

## Arguments

- df_conta:

  dataframe containing abundance and risk level association.

## Value

ggplot object.

## Examples

``` r
if (FALSE) { # \dontrun{
plot_risk_summ_sampleset(df_conta)
} # }
```
