# Scale fill risk level

Sets the fill colour scale of the risk level

## Usage

``` r
scale_fill_risk_level(..., option = "plasma", direction = 1)
```

## Arguments

- ...:

  additional arguments passed to the underlying ggplot2 scale function.

- option:

  name of colour scheme ("RdOrBlu", "plasma").

- direction:

  sets order of risk levels.

## Value

None
