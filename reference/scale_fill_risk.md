# Fill scale risk

Sets fill scale of risk colours

## Usage

``` r
scale_fill_risk(..., option = "plasma", direction = 1)
```

## Arguments

- ...:

  additional arguments passed to the underlying ggplot2 scale function.

- option:

  name of colour palette ("RdOrBlu", "plasma").

- direction:

  value that sets the order of risk levels.

## Value

None
