# Get string information for Maintainer

Get string information for Maintainer

## Usage

``` r
get_maintainer(
  email = "davidgz.science@gmail.com",
  github = "https://github.com/DavidGZ1/HowDirty"
)
```

## Arguments

- email:

  A character vector for email address to contact maintainer

- github:

  A character vector for github repository to submit issue/feature
  requests

## Value

A character vector with Maintainer information
