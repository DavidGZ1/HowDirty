# Colour scale risk

Set the colour scale and names for risk

## Usage

``` r
scale_color_risk(..., option = "plasma", direction = 1, verbose = FALSE)
```

## Arguments

- ...:

  additional arguments passed to the underlying ggplot2 scale function.

- option:

  colour palette name ("RdOrBlu", "plasma").

- direction:

  integer; sets the order of the risk level colour scale.

- verbose:

  logical; if TRUE uses risk label names instead of integers.

## Value

None
