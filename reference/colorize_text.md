# Colorize html output

Render html or latex output with a specified color, based on
https://bookdown.org/yihui/rmarkdown-cookbook/font-color.html

## Usage

``` r
colorize_text(x, color)
```

## Arguments

- x:

  string.

- color:

  string with the color code.

## Value

html-formated string.

## Examples

``` r
if (FALSE) { # \dontrun{
colorize_text("this text is red", "red")
} # }
```
