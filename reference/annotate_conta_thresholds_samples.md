# Annotate contaminant

Annotates the contaminants with risk level thresholds

## Usage

``` r
annotate_conta_thresholds_samples(df_conta_summ_sample, df_threshold_sample)
```

## Arguments

- df_conta_summ_sample:

  dataframe containing the contaminant values.

- df_threshold_sample:

  dataframe containing thresholds of risk level.

## Value

dataframe with annotated thresholds.

## Examples

``` r
if (FALSE) { # \dontrun{
annotate_conta_thresholds_samples(df_conta_summ_sample, df_threshold_sample)
} # }
```
