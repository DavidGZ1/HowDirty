# Annotate thresholds of contaminant groups

Annotates the contaminant groups with thresholds

## Usage

``` r
annotate_contagroup_thresholds(df_conta, df_threshold)
```

## Arguments

- df_conta:

  dataframe with contaminants.

- df_threshold:

  dataframe with thresholds.

## Value

dataframe containing the input dataframe

## Examples

``` r
if (FALSE) { # \dontrun{
annotate_contagroup_thresholds(df_conta, thresholds)
} # }
```
