# Summarize Contaminant Groups

Summarize the data by contaminant group

## Usage

``` r
summarize_conta(df_conta, ...)
```

## Arguments

- df_conta:

  dataframe containing the contaminant groups.

- ...:

  Variables to summarize by.

## Value

dataframe with the summarized contaminant groups.

## Examples

``` r
if (FALSE) { # \dontrun{
summarize_conta(df_conta, ContaminantGroup)
} # }
```
